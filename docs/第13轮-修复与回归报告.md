## 六、本轮追加：三套实现对齐（D 类隐患）

系统有三套实现必须保持一致：① 云函数 `prodHandler`（真·腾讯文档）② 云函数 `mockHandler`（演示）③ 前端 `utils/mock.js`（云函数不可用时的本地回退）。
新增 7 个 action 后，② ③ 出现覆盖缺口——只在演示或断网时才暴露，最难现场解释。本轮已全部补齐：

| 缺口 | 影响 | 处理 |
|---|---|---|
| `batchIo` / `reverseIO` / `listLogs` / `listAccess` 在 ②③ 缺失 | 演示/断网点击直接 404 `unknown action` | ②③ 全部补齐，规则与生产同构（合并累加、反向流水、分页形状） |
| `listStockIO` ②③ 返回裸数组 | 出入库页筛选与上拉加载失效 | 统一为 `{rows,total,offset,limit,hasMore,inQty,outQty}`，并补 `src`/`reversed` 与筛选 |
| `exportData` ②③ 仅 2–3 种 | 导出流水/申请/借还/门禁/日志报 400 | ②③ 均支持全部 7 种 |
| `usage` ②③ 无报表字段 | 概况页报表区整片空白，被误判为"页面坏了" | 补齐 `trend/trendMax/topMaterials/toolTurnover/borrow/overdue/lowStock/reqStat` |
| 借用不写「计划归还」 | 逾期清单恒为空，逾期功能形同不存在 | ②③ 借用均写 `plan`（默认 7 天） |
| 用途必填、实盘非负校验只在一侧 | 演示能提交、线上被拒；负数实盘被 `Math.max(0,…)` 悄悄吃掉 | ②③ 与生产一致：用途空 400、实盘负数 400 |
| 流水单号 `'IO'+Date.now()` 撞号 | 同毫秒连写多条时，按单号冲销会命中错误的行 | 改用单调序号 `ioNo()` |

新增两个可复用回归脚本（事件必须扁平传 `{action, ...payload}`）：

- `tools/smoke-mock.js` —— 演示模式全 action 冒烟（含权限反向用例与冲销库存回滚校验）
- `tools/smoke-local-mock.js` —— 前端本地回退全 action 冒烟
- `tools/stub-wx-server-sdk.js` —— 供 node 本地加载云函数的最小桩
