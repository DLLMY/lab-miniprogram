## 1. 物资 / 库存模块

- [ ] **入库登记**：新增物品 → 列表/库存出现，库存数 +入库量。
- [ ] **出库登记**：手动出库 → 库存数 -出库量，生成 `stock_io` 流水（src=手动出库）。
- [ ] **出入库二次确认**：提交前弹确认框，取消不写库。
- [ ] **期初建账**：`stocktake` 页 `mode=opening` → 写入期初库存基线（不是盘点增减）。
- [ ] **盘点**：`mode=stocktake` → 录实盘数与系统数差异，生成盘点记录。
- [ ] **库存快捷操作**：`inventory` 页可一键跳转某物品入库/出库，无需先进详情。
- [ ] **物品二维码**：`detail` 页生成二维码，扫码可识别该物品（扫码即办入口）。
- [ ] **搜索**：按名称/规格/编码模糊搜，结果正确。

- [ ] **教师借用**：填写计划归还日 → 生成借用单，`borrow.plan` 写入。

## 8. 重点风险 · A2 双轨出库专项（务必实操）

> 复审唯一标红的流程风险：审批通过出库 与 手动出库 双轨无单据关联，存在"同一物品被审批出库后又被手动再出库导致库存虚低"的隐患。当前靠幂等窗口防双发，**无业务关联**。

验证步骤：
1. 提交一笔领用申请（物品 X，数量 2）→ 审批通过 → X 库存 −2，流水 src=领用出库。
2. 对该物品 X **手动出库**数量 2 → 库存再 −2。
3. 观察：系统是否允许第 2 步？当前设计为**允许**（双轨独立），即库存会被扣到更低。
4. 结论记录：若实训耗材管理要求"申请单出库后不可重复手动出同一单物品"，则需补"申请单出库状态机"（标记 requisition 已出库，拦截重复）。

> 该风险不影响现有流程完整性，但真实测试中若发现库存对不上，优先查此处。
