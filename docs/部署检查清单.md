# 部署检查清单（管理员）

> 用途：把本地已开发完成的小程序 + 云函数 + WorkBuddy 集成推到真实云端，**逐项勾选**。
> 代码已就绪，本清单覆盖「控制台侧」必须手动完成的步骤。
> 完成全部勾选后，系统即可真机实测（教师查询/受控写/每日预警推送）。

---

## 一、云函数 `docsProxy` 部署

- [ ] 1. 在微信开发者工具 / CloudBase 控制台，将 `cloudfunctions/docsProxy` **上传并部署**（含本次全部改动：个人密钥、L1 确认门、`alerts` 动作、月末趋势修复）。
- [ ] 2. 配置云函数**环境变量**（控制台 → 云函数 → 配置 → 环境变量）：
  - [ ] `DATA_BACKEND=cloud`（走云数据库；若先用腾讯文档则填 `tencent` 并配腾讯文档凭证）
  - [ ] `ROBOT_KEY=<管理员自定义高强度串>`（仅你知晓，绝不给教师）
  - [ ] `ROBOT_ACTOR_ID=T001`（管理员应急超级通道身份）
- [ ] 3. **打通 WorkBuddy 与本机连接器的桥接**（二选一，推荐方案 B）：
  - **方案 B（推荐·SDK 直连，无需公网、无需升级付费）**：`cloud1` 首次创建时已**自动绑定**一个腾讯云账号（控制台没有「绑定」按钮是正常的）。用**小程序管理员**微信以「微信公众平台」方式扫码登录 [console.cloud.tencent.com](https://console.cloud.tencent.com) → **访问管理 → API 密钥管理** 创建 `SecretId`/`SecretKey`；环境 ID 在微信开发者工具「云开发 → 设置 → 环境设置」复制（形如 `cloud1-xxxxxxxx`）。本机 `mcp.json` 填 `TCB_SECRET_ID`/`TCB_SECRET_KEY`/`TCB_ENV` 三项即可，**无需在控制台建任何 HTTP 路由**。
  - **方案 A（HTTP 触发）**：在云开发控制台 **「HTTP 访问服务」**（不在函数详情的"触发器"里，触发器是给数据库/定时任务用的）为 `docsProxy` **添加路由**，路径 `/docsProxy`，**鉴权选「不鉴权」**；记录生成的公网地址（形如 `https://xxx.apigw.tencentcs.com/release/...` 或 `https://<env>.ap-shanghai.app.tcloudbase.com/docsProxy`），后续填进 `mcp.json` 的 `DOCS_PROXY_HTTP_URL`（带完整 `/docsProxy` 路径）。⚠️ 体验版环境需先升级付费才看得到入口。

> ⚠️ 切勿把 `env.local.js` 里的明文 token 直接贴到控制台；控制台环境变量与本地 `env.local.js` 二选一即可，本项目用**控制台环境变量**为准。

## 四、管理员本机 WorkBuddy 连接器

- [ ] 8. 本机 `mcp.json` 加入 `lab-docs-proxy`（推荐方案 B·SDK 直连，填 `TCB_SECRET_ID`/`TCB_SECRET_KEY`/`TCB_ENV` + `DOCS_PROXY_ROBOT_KEY`；或方案 A·HTTP 填 `DOCS_PROXY_HTTP_URL` + `DOCS_PROXY_ROBOT_KEY`）：
  ```json
  {
    "mcpServers": {
      "lab-docs-proxy": {
        "command": "node",
        "args": ["<绝对路径>/lab-miniprogram/mcp/docs-proxy-server.js"],
        "env": {
          "TCB_SECRET_ID": "<腾讯云 SecretId>",
          "TCB_SECRET_KEY": "<腾讯云 SecretKey>",
          "TCB_ENV": "cloud1-xxxxxxxx",
          "DOCS_PROXY_ROBOT_KEY": "<步骤 2 的 ROBOT_KEY 管理员密钥>"
        }
      }
    }
  }
  ```
- [ ] 9. 在 WorkBuddy 连接器列表**信任启用** `lab-docs-proxy`，发一句「查低库存物料」验证只读可用。
