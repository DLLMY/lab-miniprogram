# 部署检查清单（管理员）

> 用途：把本地已开发完成的小程序 + 云函数 + WorkBuddy 集成推到真实云端，**逐项勾选**。
> 代码已就绪，本清单覆盖「控制台侧」必须手动完成的步骤。
> 完成全部勾选后，系统即可真机实测（教师查询/受控写/每日预警推送）。

---

## 一、云函数 `docsProxy` 部署

- [ ] 1. 在微信开发者工具 / CloudBase 控制台，将 `cloudfunctions/docsProxy` **上传并部署**（含本次全部改动：个人密钥、L1 确认门、`alerts` 动作、月末趋势修复）。
- [ ] 2. 配置云函数**环境变量**（控制台 → 云函数 → 配置 → 环境变量）：
  - [ ] `DATA_BACKEND=cloud`（走云数据库；若先用腾讯文档则填 `tencent` 并配腾讯文档凭证）
  - [ ] `ROBOT_KEY=<管理员自定义高强度串>`（仅你知晓，绝不给教师）
  - [ ] `ROBOT_ACTOR_ID=T001`（管理员应急超级通道身份）
- [ ] 3. 为 `docsProxy` 创建 **CloudBase HTTP 触发**，记录生成的公网地址（形如 `https://xxx.apigw.tencentcs.com/release/...`），后续填进 `mcp.json`。

> ⚠️ 切勿把 `env.local.js` 里的明文 token 直接贴到控制台；控制台环境变量与本地 `env.local.js` 二选一即可，本项目用**控制台环境变量**为准。

---

## 二、数据源（云数据库集合）

- [ ] 4. 在云数据库新建以下集合（权限设为「仅云函数可读写」）：
  `users` / `materials` / `tools` / `requisitions` / `borrow` / `stock_io` / `access` / `logs` / `labs` / `repairs` / `inspections`
- [ ] 5. （可选）若从腾讯文档迁移，由管理员在小程序内以 super 身份调用 `migrate` 导入历史数据；源数据保留不删，可回滚。

---

## 三、小程序前端上传

- [ ] 6. 在微信开发者工具**上传**前端代码（含「我的 → 个人机器人密钥」卡片）。
- [ ] 7. 提交审核 / 体验版发布（个人主体无法认证，仅体验版 + 体验成员可见；如需搜索分享需转学校主体认证）。

---

## 四、管理员本机 WorkBuddy 连接器

- [ ] 8. 本机 `mcp.json` 加入 `lab-docs-proxy`：
  ```json
  {
    "mcpServers": {
      "lab-docs-proxy": {
        "command": "node",
        "args": ["<绝对路径>/lab-miniprogram/mcp/docs-proxy-server.js"],
        "env": {
          "DOCS_PROXY_HTTP_URL": "<步骤 3 的 HTTP 触发地址>",
          "DOCS_PROXY_ROBOT_KEY": "<步骤 2 的 ROBOT_KEY 管理员密钥>"
        }
      }
    }
  }
  ```
- [ ] 9. 在 WorkBuddy 连接器列表**信任启用** `lab-docs-proxy`，发一句「查低库存物料」验证只读可用。

---

## 五、教师自连接（每位老师各自完成）

- [ ] 10. 教师在实训室小程序「我的 → 个人机器人密钥」**生成**自己的密钥（明文仅显示一次，复制保存）。
- [ ] 11. 教师本机装 WorkBuddy + Node(≥16)，`mcp.json` 填**自己的**密钥（HTTP 地址全校共用，密钥各填各的）。
- [ ] 12. 教师信任启用后，用自然语言测试：「列出我名下待处理报修」「查 A 柜物料」。

---

## 六、每日预警自动化（已预建）

- [ ] 13. 确认 WorkBuddy 自动化 **「实训室每日预警推送」** 处于启用状态（每日 08:20），其使用的连接器为 `lab-docs-proxy`。
- [ ] 14. 次日 08:20 后查看是否收到简报；空预警应显示「今日无预警 ✅」。

---

## 七、验证与回归

- [ ] 15. 本地跑回归确认代码层无误：`node tools/regress-all.js`（应 16/16 全绿）。
- [ ] 16. 真机走一遍：教师查询直达、写操作返回 `[确认码 Cxxx]`、确认后真正写入。

---

## 八、安全红线（务必遵守）

- [ ] ❌ 绝不把管理员 `ROBOT_KEY` 发给任何教师（教师用各自个人密钥）。
- [ ] ❌ 绝不把 `env.local.js` 明文提交到公开仓库（已 gitignore）。
- [ ] ❌ 教师写操作必须经 L1 确认门，连接器不绕过。
- [ ] ✅ 密钥可随时在「我的」页吊销，吊销即失效。
